# Luma v0.5.0 — Your library, your choice

## Exclude what you do not want to see

Right-click a media item to exclude its **folder and subfolders**, **entire registered source**, or **file extension across all sources**. Confirm the scope before applying. Matching media is hidden immediately and skipped during future scans, metadata reading and preview preparation.

Open **Settings → Manage exclusions…** or **Refresh → Manage exclusions…** to review rules, add an extension before importing, choose a registered folder/source, or restore a rule. Restoration brings back already cataloged media with favorites, tags and albums intact. Refresh to discover files skipped while excluded. Reset clears browsing filters; it does not remove exclusions. Empty views explain how to restore hidden media.

Original files are untouched. Rules persist across restart and drive reconnect. Folder matching handles Unicode names and literal characters and does not accidentally hide similarly named siblings. Changing rules safely invalidates affected paused traversal checkpoints while preserving the published library. Pause active work in Activity before changing rules. Existing previews remain eligible for normal cache eviction and explicit clearing.

## A recognizable Windows app

An original layered-photo icon now appears on the EXE and native window. Windows file properties identify **Luma — Local media gallery**, version **0.5.0**, and Settings introduces **Your memories, beautifully within reach.** The editable SVG, multi-resolution ICO and regeneration script are included in the repository.

## Upgrade

Download **Luma-v0.5.0-win-x64.zip** under Assets. Close Luma, back up `%LOCALAPPDATA%\Luma` while closed, extract the entire ZIP into a fresh folder, and run **Luma.App.exe**. Keep all bundled files beside it. Existing library data is retained; no reset or re-import is needed. Older builds do not enforce exclusions.

Windows 10 version 2004+ / Windows 11, x64. Self-contained, portable and unsigned; no installer. Source code archives do not contain the EXE.
