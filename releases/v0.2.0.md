# Luma v0.2.0 — Library management

Source and maintenance controls are easier to find, while the gallery keeps its existing look and behavior.

## New controls

- **Manage sources:** see locations, item counts, connection and indexing status; browse, rename, refresh/resume or remove a source.
- **Remove from Luma:** explicit confirmation, optional current-preview removal and immediate album-count updates. Original media is never deleted by source removal.
- **Refresh:** choose the current source, all connected sources, or a scan-free status update.
- **Storage & previews:** scoped coverage, missing-preview repair, safe regeneration and confirmed preview clearing. Also accessible through Settings.
- **Clean unused previews:** reclaim space from obsolete versions and removed sources with a size estimate; retain current offline previews.
- **Activity:** live progress, pause/cancel, saved indexing checkpoints, skipped folders and recent session results.

Preview rebuilding generates replacements before overwriting old previews. Offline sources, decode failures, cancellation and insufficient cache space retain previous previews. Repair and rebuild do not evict other sources' previews.

## Install or upgrade

Download **Luma-v0.2.0-win-x64.zip** under Assets. The Source code archives do not contain the executable.

Close Luma, back up `%LOCALAPPDATA%\Luma` while closed, extract the entire ZIP into a fresh writable folder, and run `Luma.App.exe`. Keep the bundled files beside it. Your existing catalog, albums and preferences remain saved.

Windows 10 version 2004+ / Windows 11, x64. Self-contained, portable and unsigned; no installer.

## Scope and limits

Cache coverage describes the chosen source; cache space describes the whole PC-local cache. Rebuild can retain an old preview when the original cannot be regenerated. Clearing previews deliberately removes offline access to those previews. Removing a source removes its tags, favorites and album memberships; re-adding it does not restore that organization. Originals remain untouched by maintenance.

Physical-device and real-format acceptance remain ongoing. Browsing-position restoration and catalog backup/restore are deferred; this release focuses on source and preview management.
