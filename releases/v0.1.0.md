# Luma v0.1.0 — Windows portable

A local media gallery for your folders and external drives. This is the first versioned testing release.

## Included

- Persistent indexing checkpoints, resume/restart controls and skipped-folder reports.
- On this day memories using recorded capture dates, year grouping and offline previews.
- Cached-drive reopening without an automatic full scan; reconnect preserves selection and scroll.
- Continuous gallery, timeline, search, sorting, favorites, tags, virtual albums and Windows file controls.
- Refined light/dark interface and the SQLite import-lock correction.

## Download and upgrade

Download **Luma-v0.1.0-win-x64.zip** below. GitHub's automatically generated Source code archives do not contain the executable.

Close Luma, back up `%LOCALAPPDATA%\Luma` while closed, and extract the entire Windows ZIP into a fresh writable folder. Run `Luma.App.exe` with all bundled files beside it. Your existing catalog, settings and albums remain in `%LOCALAPPDATA%\Luma`.

Windows 10 version 2004+ or Windows 11, x64. Self-contained and portable; unsigned, with no installer.
