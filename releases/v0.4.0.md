# Luma v0.4.0 — Months, selection and large-library performance

## Easier browsing and file control

- **Months** opens the timeline with month headings and a month/count picker. Select a month to see only its files; **Older**, **Newer** and **All months** make navigation explicit.
- **Select** enables multiple selections with ordinary clicks or Space. Ctrl/Shift selection remains available outside this mode.
- The selection bar exposes **Copy to…**, **Copy**, **Cut**, Favorites and **More** for moves, albums, paths and selection controls. Clipboard Copy includes all selected Windows files for pasting into Explorer and remains available while indexing runs.
- Scan feedback distinguishes finding files from reading dates, shows elapsed time, and explains how to resume paused date reading.

## Performance

Indexed capture-date ordering replaces repeated full-catalog sorting. Simple counts avoid unnecessary joins; later pages reuse their count. Metadata enrichment processes missing/stale versions in batches of 100 with one transaction per completed batch. Scanning uses prepared statements, a pending-folder index and running counts. Recycled tiles cancel queued preview requests.

The 200,000-record Windows database fixture measured 8.78 ms for the first 120 items and 0.60 ms for the next page. See [performance notes](https://github.com/smile-plzz/Luma/blob/main/docs/PERFORMANCE.md) for methodology and limits. These are not HDD scan or UI frame-rate measurements; a first import can still take time. Month browsing limits the records you need to load.

## Upgrade

Download **Luma-v0.4.0-win-x64.zip** under Assets. Close Luma, back up `%LOCALAPPDATA%\Luma` while closed, extract the entire ZIP into a fresh writable folder, and run `Luma.App.exe`. Keep all bundled files beside it. Existing catalogs, organization, settings and indexing checkpoints are retained. A one-time local timeline index is built without rescanning the drive.

Windows 10 version 2004+ / Windows 11, x64. Self-contained, portable and unsigned; no installer. Source code archives do not contain the executable.
