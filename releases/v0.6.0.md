# Luma v0.6.0 — Pick up where you left off

This completes the planned Luma product build. The next stage is everyday use, feedback and defect fixes.

## Your place, remembered

Reopen the last source, folder, album, search/category and month, with the visible media item and scroll inset restored from the local catalog. This works with disconnected sources; no drive rescan is triggered.

Large collections reopen around the saved item without loading every earlier thumbnail. **Earlier items** loads the preceding 120 records without moving your view. **Back to start** returns to the beginning of the same filtered view. Disable **Remember where I left off** in Settings to start fresh. Missing sources or items receive a clear fallback message. Selection and clipboard moves are not restored.

## Progress that explains the work

**Finding media** shows saved records, examined files, completed folders, source/folder details and elapsed time. The total is unknown during discovery, so no artificial percentage is shown.

**Reading dates** shows the known pending total, checked files, committed updates and skipped unavailable/changed files. The progress bar reflects files checked. Open **Activity** or hover over the status for details, pause guidance and time since the last report. Metadata totals are per source. Previously saved media stays available while work continues.

## Refined feedback

Tooltips and accessible help explain browsing, filters, original-file actions, exclusions and maintenance. Favorites, tags, settings and pause requests acknowledge their results. Dialogs follow the gallery's light or dark appearance. Empty-state and restoration messages help recover from changes to the library.

[Complete behavior and limits](https://github.com/smile-plzz/Luma/blob/main/docs/FINAL_EXPERIENCE.md)

## Upgrade

Close Luma and back up `%LOCALAPPDATA%\Luma` while closed. Extract **Luma-v0.6.0-win-x64.zip** into a fresh folder and run **Luma.App.exe** with all bundled files beside it. Existing media, organization, previews, exclusions and settings remain intact; no re-import is needed.

Windows 10 2004+ or Windows 11, x64. Self-contained, unsigned portable package; no installer. Source code ZIPs do not contain the executable.
