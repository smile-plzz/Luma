# Luma v0.3.0 — Clearer browsing, simpler navigation

Addresses product review items 1 and 3.

## Visible media and filters

- All supported formats appear by default, including supported camera formats beyond the everyday-format subset.
- Existing installations disable the former everyday-format default once on upgrade. Explicit choices made afterward persist.
- Active source, folder, search, album, category, format, nested-folder and date filters have removable chips.
- Filtered counts show matching items against the whole library. Reset clears every content filter without changing your chosen sort or appearance.

## Simpler navigation

- **View → Show timeline** opens the Library in capture-date order with month groups.
- **Settings** and **Storage & previews** stay pinned beneath the scrolling sidebar.
- **Manage sources** owns labels, removal and source refresh/resume; **More** retains metadata refresh and confirmed indexing restart.
- **Refresh** owns explicit scan scopes and scan-free status checks. **Storage & previews** owns coverage, repair, rebuild, clearing and cleanup. **Activity** owns progress, paused indexing and reports.
- The duplicate Drive tools panel and separate Timeline destination are removed.

## Install or upgrade

Download **Luma-v0.3.0-win-x64.zip** under Assets. Close Luma, back up `%LOCALAPPDATA%\Luma` while closed, extract the entire ZIP into a fresh writable folder, and run `Luma.App.exe`. Keep all bundled files beside the executable. Catalogs, albums and other preferences are retained; only the old format-filter default is reset once.

Windows 10 version 2004+ / Windows 11, x64. Self-contained, portable and unsigned; no installer. Source code archives do not contain the executable.
